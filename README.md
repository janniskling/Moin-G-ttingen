# Moin Göttingen

A mobile-first web app for students in Göttingen — built to make navigating student life easier. Find local events, connect with other students, and discover what's going on around campus.

## Features

- **Events** — Browse local events and things to do in Göttingen
- **Community Chat** — Talk with other students in the city
- **Ranking** — Student leaderboard and social layer
- **Weather Widget** — Current local weather at a glance
- **Authentication** — User accounts with persistent profiles

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18, TypeScript, Vite |
| Styling | Tailwind CSS |
| Mobile | Capacitor (iOS & Android) |
| Routing | React Router |
| UI Components | shadcn/ui |

## Run locally

```bash
npm install
npm run dev
```

## Status

Active development. Mobile builds available via Capacitor for iOS and Android.
